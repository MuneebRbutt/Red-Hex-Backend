# Tanaura deployment guide

Use [DEPLOY_ORACLE_FREE.md](./DEPLOY_ORACLE_FREE.md) for the supported production setup: the storefront on Vercel and the Vendure backend, worker, PostgreSQL database, and persistent product assets on an Oracle Always Free VM.

The old Render deployment is intentionally no longer documented because the Render workspace is suspended and the free options do not provide dependable persistent storage for this Vendure application.
